# هيكلية الموقع العام (Website)

هذا الملف يشرح بنية الموقع التعريفي/التسويقي المرتبط بالتطبيق.

## 1) دور الموقع

- عرض خدمات المكتب بشكل احترافي.
- بناء الثقة عبر مؤشرات وإنجازات واضحة.
- تحويل الزوار إلى عملاء أو مستخدمين مسجلين.

## 2) الصفحات الأساسية

- الصفحة الرئيسية (Landing Page).
- الخدمات.
- من نحن.
- تواصل معنا.
- تسجيل الدخول/بوابة العميل.

## 3) المحتوى والتدويل

- فصل النصوص في ملفات ترجمة (locales).
- دعم ثنائي اللغة (عربي/إنجليزي) مع قابلية التوسع.
- إدارة CTA حسب حالة المستخدم (زائر/عميل مسجل).

## 4) التكامل مع النظام

- ربط بوابة العميل بنظام المصادقة المركزي.
- استهلاك APIs عامة لعرض الإحصائيات والمحتوى الديناميكي.
- الحفاظ على تجربة انتقال سلسة من الموقع إلى التطبيق.

## 5) مؤشرات الجودة

- سرعة تحميل جيدة للصفحات الأساسية.
- بنية SEO صحيحة للعناوين والوصف.
- تصميم متجاوب لجميع المقاسات.
