# هيكلية الفرونت إند (تطبيق الإدارة)

يركز هذا الملف على تطبيق الواجهة الأمامية الداخلي المستخدم من قبل فريق المكتب.

## 1) أهداف الفرونت إند

- تقديم تجربة استخدام سريعة وواضحة للأعمال اليومية.
- فصل الصفحات والميزات حسب المجالات القانونية.
- تقليل التكرار عبر مكونات مشتركة قابلة لإعادة الاستخدام.

## 2) تقسيم بنيوي مقترح

- **app/**: الإعداد العام، الراوتنج، المزودات (Providers).
- **features/**: وحدات العمل حسب المجال (cases, clients, finance...).
- **shared/**: المكونات العامة، الأدوات، الخدمات، الثيم.
- **locales/**: ملفات الترجمة والرسائل.

## 3) إدارة الحالة والبيانات

- طبقة API client موحدة للطلبات.
- إدارة حالة محلية للواجهات التفاعلية.
- كاش للبيانات المتكررة لتقليل الضغط على الباكند.
- التعامل الموحد مع الأخطاء ورسائل التنبيه.

## 4) مبادئ الواجهة

- تصميم موجه للمهام (Task-oriented UI).
- دعم اللغة العربية واتجاه RTL بشكل أصيل.
- قابلية الوصول الأساسية (لوحة مفاتيح، تباين، Labels).
- مكونات موحدة للنماذج والجداول والفلاتر.

## 5) التكامل مع الباكند

- الاعتماد على عقود API موثقة.
- عزل DTO/Transformers في طرف الواجهة عند الحاجة.
- توحيد سيناريوهات المصادقة وتحديث الجلسة.
