# هيكلية واجهة المستخدم (UI)

يركز هذا الملف على النظام المرئي (Design System) وتجربة المستخدم المشتركة بين التطبيق والموقع.

## 1) مبادئ التصميم

- الوضوح أولًا: واجهات بسيطة ومباشرة.
- الاتساق: نفس الأنماط لنفس السلوك.
- الأولوية للمعلومة القانونية المهمة.
- تقليل خطوات تنفيذ المهام المتكررة.

## 2) طبقات المكونات

- **Foundations:** الألوان، الخطوط، المسافات، الظلال.
- **Primitives:** أزرار، حقول إدخال، شارات، رسائل تنبيه.
- **Composites:** جداول، نماذج، بطاقات، نوافذ منبثقة.
- **Patterns:** صفحات التفاصيل، القوائم، لوحات المتابعة.

## 3) إرشادات تجربة المستخدم

- دعم RTL كامل.
- تغذية راجعة فورية بعد كل إجراء (نجاح/خطأ/تحميل).
- حالات واضحة عند غياب البيانات (Empty States).
- رسائل خطأ مفهومة وقابلة للتنفيذ.

## 4) قابلية الوصول

- تباين ألوان مناسب.
- دعم التنقل بلوحة المفاتيح.
- تسميات واضحة للحقول والأزرار.
- اتساق ترتيب العناصر في النماذج.

## 5) الحوكمة والصيانة

- توثيق أي مكون جديد قبل اعتماده.
- منع إنشاء مكونات مكررة دون حاجة.
- مراجعة دورية للأنماط غير المستخدمة.
