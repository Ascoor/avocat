# الهيكلية العامة للتطبيق

هذا الملف يقدم تصورًا عالي المستوى لمنصة إدارة مكاتب المحاماة، وكيف تتكامل الأجزاء الأساسية مع بعضها.

## 1) مكونات النظام الأساسية

- **Backend API (Laravel):** مسؤول عن قواعد العمل، الصلاحيات، البيانات، والتكاملات.
- **Frontend App (React):** لوحة التحكم والتطبيق الداخلي للمحامين والموظفين.
- **Public Website:** واجهة تسويقية وتعريفية وبوابة دخول العملاء.
- **User Interface Layer:** نظام المكونات المرئية وتجربة المستخدم المشتركة.

## 2) تدفق العمل العام

1. المستخدم يسجل الدخول عبر واجهة التطبيق أو البوابة.
2. الطلبات تنتقل إلى الـ API مع التحقق من الهوية والصلاحيات.
3. الـ Backend ينفذ قواعد العمل ويعيد استجابة معيارية.
4. الواجهة تعرض البيانات عبر مكونات UI موحدة.

## 3) المجالات الوظيفية الرئيسية

- إدارة القضايا والجلسات والإجراءات.
- إدارة العملاء والمستندات.
- الفوترة والمدفوعات والتقارير.
- الإشعارات وسجل الأنشطة.

## 4) مبادئ معمارية معتمدة

- فصل واضح بين طبقة العرض وطبقة الأعمال.
- قابلية التوسع عبر وحدات مستقلة (Modular Domains).
- اعتماد API contracts ثابتة بين الباكند والفرونت إند.
- توحيد المصطلحات بين الفرق (قضية، جلسة، إجراء، فاتورة...).
