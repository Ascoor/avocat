# UI QA Guide

## الوصول
- افتح المسار: `/dashboard/tools/qa`.
- ستجد لوحة التحقق من الدخول، التنقل بين الأقسام، اختبارات CRUD، وفاحص ربط الجدول.

## Auth Check Panel
- يعرض حالة وجود token والمستخدم الحالي.
- زر "فتح صفحة الدخول" يعيد توجيهك للـ login مع حفظ `next`.
- زر "تنفيذ طلب اختبار" ينفذ طلبًا سريعًا على `/legal-cases` ويعرض النتيجة.

## Section Navigator
- قائمة بالأقسام الأساسية مع زر فتح سريع.
- سجل نشاط يعرض:
  - المسار الحالي.
  - آخر طلبات API.
  - آخر الأخطاء.

## CRUD Smoke Tests
- أدخل ID مناسب لكل قسم.
- الأزرار المتاحة:
  - Load/List: تحميل القائمة.
  - View One: اختبار endpoint لعنصر واحد.
  - Open Add Modal: فتح مودال الإضافة بدون حفظ.
  - Edit First Row: فتح مودال التعديل لأول صف.
  - Delete First Row: تنفيذ حذف بعد تأكيد واضح.

## Table Wiring Inspector
- يعرض جدولًا تجريبيًا بـ `TableComponent`.
- يفحص:
  - صحة الـ headers.
  - تفرد الـ keys.
  - استقرار الـ row id.
  - صلاحية customRenderers.

## جمع لوج
- سجل النشاط يظهر آخر 15 حدثًا.
- استخدمه لالتقاط الأخطاء السريعة أو تكرار الطلبات.
