# Lexicraft Icons (Vendor)

هذا المجلد مخصص لاستيراد مشروع Lexicraft Icons كمصدر ثابت داخل المستودع.

> ملاحظة: محاولة السحب من GitHub فشلت بسبب قيود الشبكة (HTTP 403 عند الاتصال عبر الـ CONNECT tunnel).
> يرجى إعادة المحاولة محليًا عبر الأمر:
>
> ```bash
> git clone --depth 1 https://github.com/AscarTec/lexicraft-icons avocat-frontend/_vendor/lexicraft-icons
> ```
>
> ثم تحديث ملفات التكامل ضمن `src/shared/icons/lexicraft` وملف القفل `LEXICRAFT_SOURCE_LOCK.md`.
